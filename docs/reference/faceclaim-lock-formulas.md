# สูตรทะเบียนล็อกเฟซเคลม

> อ้างอิงประวัติการออกแบบ ไม่ใช่คำสั่งให้แก้ชีตปัจจุบัน รายละเอียดบางส่วนอาจเก่ากว่า docs/admin-flow.md และสูตร native ที่ใช้อยู่ โดยเฉพาะนิยามวันหมดอายุและการต่ออายุ ต้องตรวจชีตล่าสุดและยืนยันกติกาก่อนนำไปใช้ ห้ามใช้เอกสารนี้ตัดสินประเด็นที่ยังค้างเอง

ฉบับแก้หน้าสรุป: เพิ่ม Q ใน log เป็นเลขแถวจริง และใช้ MAXIFS หาเหตุการณ์ล่าสุดแทน FILTER เดิม สูตร L:P ที่ตรวจผ่านแล้วไม่ต้องแก้

ใช้กับหัวคอลัมน์ในไฟล์ที่ตรวจล่าสุด ชีตต้นฉบับและ dashboard ยังไม่ต้องเปลี่ยนแหล่งข้อมูล

## ข้อตกลงการนับ

- ซื้อเวลาเป็นเดือนปฏิทินด้วย EDATE เหมือนสูตรเดิม
- End Date คือวันสิ้นสิทธิ์: ถึงวันที่นั้นถือว่าหมดอายุ ตามแนวสูตร All Lock เดิมที่ใช้ End Date > TODAY()
- ตัวอย่าง เริ่ม 9 มิถุนายน 1 เดือน มี End Date = 9 กรกฎาคม; ถ้าพักวันที่ 27 กรกฎาคมก่อน End Date = 9 สิงหาคม จะเหลือ 13 วัน
- วันที่พักหยุดใช้เวลา และวันที่เริ่มนับต่อเริ่มใช้เวลาอีกครั้ง จึงไม่บวกวันซ้ำระหว่างช่วง
- ต่ออายุขณะกำลังนับ: บวกเดือนจากวันหมดอายุเดิม หรือวันอนุมัติใหม่หากหมดอายุแล้ว
- ต่ออายุขณะพัก: คำนวณวันหมดอายุเสมือนเริ่มนับต่อในวันอนุมัติ แล้วเพิ่มเดือนจากวันนั้นที่ควรหมดอายุ เก็บผลเป็นวันคงเหลือและยังคงพักอยู่ เช่น เหลือ 13 วัน ต่อ 1 เดือนวันที่ 1 ตุลาคม จะคำนวณ EDATE(1 ตุลาคม + 13 วัน,1) - 1 ตุลาคม
- หลังยกเลิกแล้ว ถ้าขอล็อกใหม่ให้ใช้ LockID ใหม่
- เหตุการณ์ของ LockID เดียวกันต้องเรียงตามวันที่ และตามลำดับที่เกิดจริงหากเป็นวันเดียวกัน
- คอลัมน์ D/E เป็นรหัสที่ยืนยันแล้ว เก็บเป็นค่าคงที่ ไม่ค้นชื่อย้อนหลังใหม่เมื่อชื่อเปลี่ยน
- ข้อมูลตัวละครและเฟซเคลมที่เปลี่ยนไปเป็นคนละสิทธิ์ต้องไม่ใช้ LockID เดิม; เปลี่ยนชื่อตัวละครเดิมยังใช้ CharID เดิมได้
- สูตรรองรับแถวถึง 10000; เกินจากนั้นต้องขยายทุกช่วงที่เกี่ยวข้อง

## 1. คอลัมน์ช่วยใน log เฟซเคลมล็อก new

หัวเดิม A:K ต้องเป็น:

```text
EventID | LockID | logID (#Post) | CharID | UserID | Lock Character Name | Lock Face Claim | Type | Effective Date | Lock Time (Month) | Note
```

เพิ่มหัวคอลัมน์ต่อท้าย โดยไม่แทรกระหว่างคอลัมน์เดิม:

| ช่อง | หัวคอลัมน์ | ความหมาย |
|---|---|---|
| L1 | Previous Event Row | แถวก่อนหน้าของสิทธิ์เดียวกัน |
| M1 | State After Event | สถานะทันทีหลังเหตุการณ์ |
| N1 | Days After Event | วันคงเหลือทันทีหลังเหตุการณ์ ไม่ใช่ยอด ณ วันนี้ |
| O1 | End Date After Event | วันสิ้นสิทธิ์หลังเหตุการณ์; ว่างเมื่อพักหรือยกเลิก |
| P1 | Check | ตรวจข้อมูลก่อนคำนวณ |
| Q1 | Event Row | เลขแถวจริงสำหรับให้หน้าสรุปค้นเหตุการณ์ล่าสุด |

ตั้ง N เป็นตัวเลข และ O เป็นวันที่ คอลัมน์ช่วยซ่อนได้หลังตรวจผลแล้ว

### L2

```gs
=IF(B2="","",IFNA(MAX(FILTER(
  ARRAYFORMULA(ROW($B$1:B1)),
  $B$1:B1=B2
)),0))
```

### P2

```gs
=IF(B2="","",
  LET(
    previousState,IF(L2=0,"",INDEX($M$1:M1,MAX(1,L2))),
    previousDate,IF(L2=0,0,N(INDEX($I$1:I1,MAX(1,L2)))),
    previousEnd,IF(L2=0,0,N(INDEX($O$1:O1,MAX(1,L2)))),
    previousChar,IF(L2=0,D2,INDEX($D$1:D1,MAX(1,L2))),
    previousFace,IF(L2=0,G2,XLOOKUP(B2,$B$1:B1,$G$1:G1,"")),
    isPurchase,OR(H2="เริ่มล็อก",H2="ต่ออายุ"),
    validMonths,IF(ISNUMBER(J2),AND(J2>0,J2=INT(J2)),FALSE),
    IFS(
      A2="","ขาด EventID",
      COUNTIF($A$2:$A$10000,A2)>1,"EventID ซ้ำ",
      D2="","ขาด CharID",
      E2="","ขาด UserID",
      NOT(ISNUMBER(I2)),"วันที่ต้องเป็นวันที่จริง",
      ISNA(MATCH(H2,{"เริ่มล็อก","ต่ออายุ","พักนับ","เริ่มนับต่อ","ยกเลิก"},0)),"ประเภทไม่ถูกต้อง",
      AND(isPurchase,NOT(validMonths)),"จำนวนเดือนต้องเป็นจำนวนเต็มบวก",
      AND(NOT(isPurchase),J2<>""),"ประเภทนี้ให้เว้นจำนวนเดือน",
      AND(H2="เริ่มล็อก",G2=""),"ขาดชื่อเฟซเคลม",
      AND(L2=0,H2<>"เริ่มล็อก"),"ต้องมีเหตุการณ์เริ่มล็อกก่อน",
      AND(L2>0,H2="เริ่มล็อก"),"LockID นี้เริ่มล็อกแล้ว",
      AND(L2>0,I2<previousDate),"วันที่ย้อนหลังจากเหตุการณ์ก่อนหน้า",
      previousState="ตรวจสอบข้อมูล","แก้เหตุการณ์ก่อนหน้าก่อน",
      AND(L2>0,D2<>previousChar),"CharID ต่างจากสิทธิ์เดิม",
      AND(L2>0,G2<>"",LOWER(TRIM(G2))<>LOWER(TRIM(previousFace))),"เฟซเคลมต่างจากสิทธิ์เดิม",
      AND(H2="ต่ออายุ",previousState="ยกเลิก"),"ยกเลิกแล้วให้ใช้ LockID ใหม่",
      AND(H2="พักนับ",OR(previousState<>"กำลังนับ",previousEnd<=I2)),"พักได้เฉพาะสิทธิ์ที่ยังมีเวลา",
      AND(H2="เริ่มนับต่อ",previousState<>"พักนับ"),"สิทธิ์นี้ไม่ได้พักนับอยู่",
      AND(H2="ยกเลิก",previousState="ยกเลิก"),"สิทธิ์นี้ยกเลิกแล้ว",
      TRUE,"OK"
    )
  )
)
```

### M2

```gs
=IF(B2="","",
  IF(P2<>"OK","ตรวจสอบข้อมูล",
    LET(
      previousState,IF(L2=0,"",INDEX($M$1:M1,MAX(1,L2))),
      SWITCH(H2,
        "เริ่มล็อก","กำลังนับ",
        "ต่ออายุ",IF(previousState="พักนับ","พักนับ","กำลังนับ"),
        "พักนับ","พักนับ",
        "เริ่มนับต่อ","กำลังนับ",
        "ยกเลิก","ยกเลิก"
      )
    )
  )
)
```

### N2

```gs
=IF(B2="","",
  IF(P2<>"OK","",
    LET(
      previousState,IF(L2=0,"",INDEX($M$1:M1,MAX(1,L2))),
      previousDays,IF(L2=0,0,N(INDEX($N$1:N1,MAX(1,L2)))),
      previousEnd,IF(L2=0,0,N(INDEX($O$1:O1,MAX(1,L2)))),
      SWITCH(H2,
        "เริ่มล็อก",EDATE(I2,J2)-I2,
        "ต่ออายุ",IF(previousState="พักนับ",
          EDATE(I2+previousDays,J2)-I2,
          EDATE(MAX(previousEnd,I2),J2)-I2
        ),
        "พักนับ",previousEnd-I2,
        "เริ่มนับต่อ",previousDays,
        "ยกเลิก",0
      )
    )
  )
)
```

### O2

```gs
=IF(B2="","",IF(P2<>"OK","",IF(M2="กำลังนับ",I2+N2,"")))
```

### Q2

```gs
=IF(B2="","",ROW())
```

หลังใส่ครบทั้ง 6 สูตรที่แถว 2 ให้เลือก L2:Q2 แล้วลากลงถึงแถว 17 หากทำ L:P ไว้แล้วให้เพิ่มเฉพาะ Q2 แล้วลาก Q ลง

ตรวจ P2:P17 ต้องเป็น OK ทั้งหมด ตัวอย่าง L4 = 2, L7 = 3, L8 = 7

## 2. หน้าสรุป Faceclaim Locks

ใช้หัว A:I เดิม ไม่ต้องกรอกข้อมูลสิทธิ์ซ้ำ

### A2: รายการสิทธิ์อัตโนมัติ

สูตรนี้ขยายลงเอง ไม่ต้องลาก และ A2:A ต้องว่างก่อนวางสูตร

```gs
=IFNA(UNIQUE(FILTER(
  'log เฟซเคลมล็อก new'!$B$2:$B$10000,
  'log เฟซเคลมล็อก new'!$B$2:$B$10000<>""
)),"")
```

### B2: UserID

```gs
=IF(A2="","",XLOOKUP(A2,
  'log เฟซเคลมล็อก new'!$B$2:$B$10000,
  'log เฟซเคลมล็อก new'!$E$2:$E$10000,""
))
```

### C2: CharID

```gs
=IF(A2="","",XLOOKUP(A2,
  'log เฟซเคลมล็อก new'!$B$2:$B$10000,
  'log เฟซเคลมล็อก new'!$D$2:$D$10000,""
))
```

### D2: ชื่อตัวละครปัจจุบัน

ถ้าตัวละครไม่อยู่ใน Characters แล้ว จะใช้ชื่อใน log แทน

```gs
=IF(A2="","",XLOOKUP(C2,
  Characters!$G$2:$G$10000,
  Characters!$B$2:$B$10000,
  XLOOKUP(A2,
    'log เฟซเคลมล็อก new'!$B$2:$B$10000,
    'log เฟซเคลมล็อก new'!$F$2:$F$10000,""
  )
))
```

### E2: เฟซเคลมของสิทธิ์

ใช้เฟซเคลมที่เริ่มล็อก ไม่ใช่เฟซเคลมปัจจุบันใน Characters

```gs
=IF(A2="","",XLOOKUP(A2,
  'log เฟซเคลมล็อก new'!$B$2:$B$10000,
  'log เฟซเคลมล็อก new'!$G$2:$G$10000,""
))
```

### F2: สรุปสามคอลัมน์ F:H

ล้าง F2:H ก่อนวาง สูตร F2 จะแสดง Status / Remaining Days / End Date พร้อมกัน

ลบกฎการตรวจสอบข้อมูล (Data validation / dropdown) เดิมจาก F2:H ด้วย เพราะเป็นผลลัพธ์จากสูตร ไม่ใช่ช่องเลือกสถานะเอง การล้างค่าอย่างเดียวไม่ลบกฎนี้

```gs
=IF(A2="","",
  LET(
    latestRow,MAXIFS(
      'log เฟซเคลมล็อก new'!$Q$2:$Q$10000,
      'log เฟซเคลมล็อก new'!$B$2:$B$10000,A2,
      'log เฟซเคลมล็อก new'!$I$2:$I$10000,"<="&TODAY(),
      'log เฟซเคลมล็อก new'!$I$2:$I$10000,">0"
    ),
    IF(latestRow=0,HSTACK("รอเริ่ม","",""),
      LET(
        eventState,INDEX('log เฟซเคลมล็อก new'!$M$1:$M$10000,latestRow),
        eventDays,N(INDEX('log เฟซเคลมล็อก new'!$N$1:$N$10000,latestRow)),
        eventEnd,N(INDEX('log เฟซเคลมล็อก new'!$O$1:$O$10000,latestRow)),
        HSTACK(
          SWITCH(eventState,
            "กำลังนับ",IF(eventEnd>TODAY(),"กำลังนับ","หมดอายุ"),
            "พักนับ","พักนับ",
            "ยกเลิก","ยกเลิก",
            "ตรวจสอบ log"
          ),
          SWITCH(eventState,
            "กำลังนับ",MAX(0,eventEnd-TODAY()),
            "พักนับ",eventDays,
            "ยกเลิก",0,
            ""
          ),
          IF(eventState="กำลังนับ",eventEnd,"")
        )
      )
    )
  )
)
```

### I2: หมายเหตุล่าสุดที่มีผลแล้ว

```gs
=IF(A2="","",
  LET(
    latestRow,MAXIFS(
      'log เฟซเคลมล็อก new'!$Q$2:$Q$10000,
      'log เฟซเคลมล็อก new'!$B$2:$B$10000,A2,
      'log เฟซเคลมล็อก new'!$I$2:$I$10000,"<="&TODAY(),
      'log เฟซเคลมล็อก new'!$I$2:$I$10000,">0"
    ),
    IF(latestRow=0,"",INDEX('log เฟซเคลมล็อก new'!$K$1:$K$10000,latestRow))
  )
)
```

ลาก B2:F2 และ I2 ลงตามจำนวนสิทธิ์ (ตอนนี้ถึงแถว 9) ไม่ลาก G/H เพราะรับผลจาก F

ตั้ง G เป็นตัวเลข และ H เป็นวันที่ ช่อง H ของสิทธิ์พักนับจะว่าง เพราะยังไม่ทราบว่าจะเริ่มนับต่อวันใด
